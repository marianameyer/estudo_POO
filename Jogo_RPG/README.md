# Exercício RPG

## Exercício de Fixação: Personagens de um Jogo

1) Todo personagem tem um nome e método atacar(), que exibe uma mensagem genérica.
2) Crie as subclasses Guerreiro, Mago e Arqueiro, cada uma sobrescrevendo atacar() com sua própria mensagem (use @Override).
3) O Mago tem também o método lancarFeitico(), que só ele possui.
4) Sobrescreva toString() em Personagem para exibir o nome do personagem.
5) No main, crie um vetor com 4 personagens de tipos variados. 
6) Em um laço, chame atacar() de cada  um; se o personagem for um Mago, chame também lancarFeitico().
